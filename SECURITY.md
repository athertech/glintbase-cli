# Security Policy

## Supported Versions

We actively support and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

The Glintbase team takes security vulnerabilities seriously. If you discover a potential vulnerability within `@glintbase/cli`, please do **not** disclose it publicly via GitHub issues or discussions.

### How to Report
1. Email your report directly to **security@glintbase.xyz** (or **info@glintbase.xyz**).
2. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce the issue (proof of concept script, command arguments, or payload).
   - The impact of the vulnerability.
   - Potential mitigation or remediation steps, if known.

### Response Timeline
- **Initial Response**: Within 48 hours of receipt.
- **Triage & Validation**: Within 5 business days.
- **Fix & Disclosure**: Coordinated release with security advisory.

We greatly appreciate responsible disclosure and will credit researchers in our release notes unless anonymity is requested.
